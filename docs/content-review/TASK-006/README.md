## Research boundaries

- Source access dates are recorded per source. Sources in the JSON records are primary vendor documentation, vendor pricing pages or official project repositories.
- Aider's official Git guide says it commits pre-existing dirty changes before editing and skips Git hooks by default unless configured otherwise. This risk is surfaced in its profile and must be reviewed before any recommendation.
- Aider's analytics documentation says it asks a random subset of users to opt in, records selected models/token counts, feature and command use, edit formats and errors against a random UUID4, and excludes code, prompts/chats, API keys and personal information from these product analytics. `--no-analytics` disables a session and `--analytics-disable` opts out permanently. Its privacy policy separately describes tool-interaction analytics; neither page determines selected model-provider data handling or any local consent setting. Sources: [Analytics](https://aider.chat/docs/more/analytics.html) and [Privacy policy](https://aider.chat/docs/legal/privacy.html), accessed 2026-09-27; the policy page says last updated 2025-04-12.
- Aider's official Docker guide describes two client images and mounts the repository into `/app`; its example passes an OpenAI API key. This establishes containerized client execution, not local inference or provider-independent data handling. Sources: [Aider with Docker](https://aider.chat/docs/install/docker.html) and [Connecting to language models](https://aider.chat/docs/llms.html), accessed 2026-09-27.
- n8n's Privacy Policy says self-hosted deployments process certain usage data unless users opt out, including user identifiers, settings, events, workflow metrics and enabled integrations; it says opt-out applies with future effect. Its security page assigns self-hosters TLS termination and at-rest encryption. These statements do not establish a deployment's actual settings or data flows through connected services. Sources: [Privacy Policy](https://n8n.io/legal/privacy/) and [Security](https://n8n.io/legal/security/), accessed 2026-09-27.
- Cline's Terms last modified 2025-09-25 say extension telemetry is on by default and can be disabled in settings; its 2025-02-26 telemetry blog describes collection as opt-in. The later-dated Terms are recorded, with the public-source conflict visible. Its Privacy Notice distinguishes user-owned API keys, where it says Cline does not collect User Content, from Cline-provided keys, where it collects content to facilitate provider requests. No client setting/payload or selected model-provider terms were inspected. Sources: [Terms](https://cline.bot/tos), [Privacy Notice](https://cline.bot/privacy), and [telemetry post](https://cline.bot/blog/introducing-anonymous-telemetry-in-cline), accessed 2026-09-28.
- Continue's official site says it joined Cursor and that the open-source code remains available. Its README calls the repository read-only/no longer actively maintained and describes a final 2.0.0 release for VS Code, CLI and JetBrains. JetBrains Marketplace calls its plugin community-maintained and says active development is happening in CLI. These statements conflict about the CLI lifecycle; they do not establish support for a selected package. The CLI quickstart lists a Continue account or Anthropic API key, with Node.js 20+ for npm installation, but does not establish account/provider price or data terms. Sources: [Continue announcement](https://continue.dev/), [upstream README](https://github.com/continuedev/continue), [CLI quickstart](https://docs.continue.dev/cli/quickstart), [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/22707-continue), accessed 2026-09-28.
- Continue's model docs list local Ollama models and caution that they need sufficient VRAM and may have limited tool-calling/reasoning. Its offline IDE guide instructs users to install a VS Code extension, disable "Allow Anonymous Telemetry" and configure a local model; this is a documented setup path, not a test of a package or all client channels. Its Privacy Notice says last updated 2026-02-05, describes log and analytics/activity collection from open-source offerings unless users opt out, and explicitly excludes customer content processed on a customer's behalf when Continue acts as processor. The notice does not establish applicability to a selected post-acquisition package, actual settings/traffic or provider terms. Sources: [models](https://docs.continue.dev/customize/models), [offline setup](https://docs.continue.dev/guides/running-continue-without-internet), and [Privacy Notice](https://continue.dev/privacy/), accessed 2026-09-28.
