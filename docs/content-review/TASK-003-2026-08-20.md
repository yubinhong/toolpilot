## 使用规则

- `http-ok` 表示本次 HTTP 检查返回 2xx/3xx；它只证明请求可完成，不证明页面内容、价格、功能、限制、更新时间或商业条款正确。
- `reachable-restricted` 表示目标可解析或返回了受防护/限流响应（本次为 403/429）；不能据此完成内容核验。
- `provided` 只表示研究快照有 `sourceUrl`；来源是否权威、是否最新和是否支持具体说法仍需编辑确认。
- `missing` 表示当前快照没有来源 URL，必须在正式发布前补齐来源或删除相应主张。
- 所有条目当前为 `Draft`、`pending-editorial`、`reviewOwner=TBD`、`reviewedAt=null`、`verifiedAt=null`。

## Formal publish gate

只有当每条记录同时满足以下条件，才允许从 Draft 进入正式内容审核后的发布状态：

- 产品官网 URL 已由编辑人工打开并确认指向正确产品。
- 每个关键产品事实都有可追溯、带检查日期的来源；来源缺失项已补齐。
- 价格、功能、限制和适用场景经过编辑事实核验，并记录 `reviewOwner`、`reviewedAt` 和 `verifiedAt`。
- Affiliate、Partner、Referral、Featured 或 Sponsor 关系分别核验，用户可见披露文案已批准。
- 受防护/限流的 URL 已通过浏览器或其他可审计证据复核；不能把 403/429 标记为已验证。
